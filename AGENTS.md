# Agent Development Guide

Cross-Media's skill catalogue. Vocabulary is defined in [CONTEXT.md](CONTEXT.md) — use those terms.

Keep responses focused, brief, and concise. Keep disclaimers and caveats short, and spend most of the response on the main answer. End the response when the answer is complete — do not add a summary, offer, or closing remarks. Give a little context before diving in — enough that the answer stands on its own. Write in Simplified Technical English (the ASD-STE100 style used in aviation manuals): short sentences, one idea per sentence, plain everyday words, active voice, present tense. Pick one term for each concept and use only that term throughout — never switch between synonyms for the same thing.

## Commands

- **Check everything:** `mise validate` — read-only, fails on drift.
- **Regenerate the plugin's skill list:** `mise sync-plugin`.
- **Use this repo's skills here:** `mise link-skills` — symlinks `skills/` into `.claude`, `.agents`
  and `.pi`, so edits are live. `mise clear` removes them.

`mise install` and `mise link` are mise's own commands, which is why the task is `link-skills`.

Run `mise validate` before proposing a commit. It is what CI runs, so a green run locally means a
green run there.

## Layout

- `skills/<name>/SKILL.md` — one Skill per directory. `name` in the frontmatter must equal the
  directory name; `mise validate` enforces it.
- `.claude-plugin/plugin.json` — the Claude Code plugin. Its `skills` array is generated by
  `mise sync-plugin`, never hand-edited, and its `version` is bumped by hand at release.

## Authoring a skill

Skills are installed by `npx skills`, which reads `SKILL.md` frontmatter and nothing else — no
manifest entry is needed for that channel. A Skill that is not ready to ship carries
`metadata.internal: true`, which hides it from the picker and excludes it from the plugin.

Write for every Agent target, not just Claude Code. Claude-specific syntax (`@file` imports,
tool names, subagent types) makes a Skill silently weaker on `codex`, `opencode` and `pi`.
